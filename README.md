# Jassi Birthday Website 🎂❤️

A premium, aesthetic birthday website made for Jassi by Jatin.

## Folder structure

```text
Jassi_Birthday_Website/
├── index.html
├── style.css
├── script.js
├── assets/
│   └── jassi-family-photo.jpeg
└── music/
    └── inaam.mp3   ← add your legally obtained audio file here
```

## Change anything yourself

Open `index.html` in VS Code. All text is directly written there.

- Change name: search for `Jassi`
- Change sender: search for `Jatin`
- Change birthday message: edit the paragraphs inside `<article class="letter">`
- Change photo: replace `assets/jassi-family-photo.jpeg` with your own photo, keeping the same filename.
- Change music: put the audio file at `music/inaam.mp3`. If your file has another name, edit the `<source src="...">` line in `index.html`.
- Colors/fonts/layout: edit `style.css`
- Animations/buttons: edit `script.js`

## Test on PC

Double-click `index.html`. It will open in Chrome.

For music, browsers normally require the visitor to click the **Play Music** button first.

## GitHub Pages

1. Create a new GitHub repository, for example `jassi-birthday`.
2. Upload **all files and folders** from this project.
3. Open repository **Settings → Pages**.
4. Under Build and deployment, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then Save.
6. GitHub will give you a public website link.

### Important
Do not upload copyrighted music unless you have the right/permission to use it. The project intentionally contains no copyrighted song file.
